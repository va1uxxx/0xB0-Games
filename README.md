**0xB0 Games** is a free browser arcade built for places where fun gets filtered out — school Chromebooks, locked-down Wi-Fi, boring study halls. No downloads, no accounts, no blocked .exe files: open the link and press play. And when a game isn't enough, it doubles as a full **website unblocker**.

## 🚀 How to play

1. **Open the site** → [va1uxxx.github.io/0xB0-Games](https://va1uxxx.github.io/0xB0-Games/)
2. **Pick a game** — search it, filter it, or hit Random 🎲
3. **Need a website instead of a game?** Open the **Unblocker** ⛩️ and type any address

Everything runs in the browser — Chromebook-friendly, phone-friendly, school-filter-tested.
