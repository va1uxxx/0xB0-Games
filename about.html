About 0xB0 Games

The unblocked sakura arcade

> what_is_this

0xB0 Games is a free, browser-based arcade for places where fun gets filtered out. It runs entirely in your browser — no downloads, no installs, no accounts. Just open the link and press play.

> how_it_works

The site is 100% static (HTML + CSS + JavaScript) hosted on GitHub Pages. It includes 15 hand-built neon originals plus 490+ games linked from public hosts across the web. Every game opens in our clean player with fullscreen, reload, and tab-cloaking built in.

> features

🔍 Instant search & 12 category filters
🎲 Random game button
🎨 6 themes + falling petals
🕶️ Tab disguise (Google Docs, Drive, Canvas…)
⌨️ Panic key — press ` to teleport
🕶️ Boss mode — blur the page when you switch away
🎮 Request games via GitHub Issues

> privacy

We collect nothing. No accounts, no trackers, no analytics, no cookies (except your own browser's localStorage for settings). Your school can't see what you play because the site never sends data anywhere.
